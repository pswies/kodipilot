# kodipilot

## Communication

- **Disambiguate "I" and "you" only where answer choices make them ambiguous.** In ordinary prose — status, reports, explanations — "I" means the assistant and "you" means the user naturally; do not tag them there. Add "(user)" or "(assistant)" only when a question's answer options are themselves phrased with "I"/"you" (e.g. "I drive the writes" vs "you drive the writes"), where it is unclear whether an option is written from the user's point of view as the chooser or is the assistant's own wording to be selected — tag those so the referent is fixed.
